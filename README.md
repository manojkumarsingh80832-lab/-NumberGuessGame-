# Number Guessing Game (Java)

A simple console-based Number Guessing Game built in Java to practice fundamental programming concepts like loops, conditional statements, and random number generation.

## How It Works

1. The program generates a random secret number between **1 and 100**.

2. The user is prompted to guess the number.

3. Based on the user's input, the program gives hints:
   - **"Bahut chhota number hai!"** if the guess is too low.
   - **"Bahut bada number hai!"** if the guess is too high.

4. The game continues in a loop until the user guesses the exact secret number.

## Prerequisites

Make sure you have **Java Development Kit (JDK)** installed on your system.

## How to Run

1. Clone the repository or download the `NumberGuessGame.java` file.

2. Open your terminal or command prompt and navigate to the folder containing the file.

3. Compile the Java file:
   ```bash
   javac NumberGuessGame.java
